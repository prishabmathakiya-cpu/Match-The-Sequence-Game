# Match-The-Sequence-Game
This is a simple game built using HTML, CSS, JavaScript. <br><br>
<hr>
<b>❓How to Play</b><br>
1. Press any key to start the game.<br>
2. Carefully watch teh sequence of the colors flashed on the screen.<br>
3. Click on the same color buttons and match the sequence.<br>
4. If you mess up with sequence the game ends, you can see your score and press any key to start the game.<br>
