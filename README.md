# Match-The-Sequence-Game
This is a simple game built using HTML, CSS, JavaScript. <br>
<hr>
<b>❓How to Play</b><br>
1. Press any key to start the game.<br>
2. Carefully watch teh sequence of the colors flashed on the screen.<br>
3. Click on the same color buttons and match the sequence.<br>
4. If you mess up with sequence the game ends, you can see your score and press any key to start the game.<br><br>

<b>💻 Tech Stack</b><br>
<b>HTML5</b>: To create main structure.<br>
<b>CSS3</b>: To add colors and layout.<br>
<b>JavaScript</b>: For the logic of the game.<br><br>

<b>📁 Files</b><br>
<b>miniproj.html</b>: Contains html code.<br>
<b>miniprojstyle.css</b>: Contains css code.<br>
<b>miniproj.js</b>: Contains js code.<br>
<b>sequencegame.png</b>: Image of the game.<br>
